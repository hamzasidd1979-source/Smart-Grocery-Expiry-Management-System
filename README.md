# Smart Grocery & Expiry Management System

## Overview
The Smart Grocery & Expiry Management System is designed to manage grocery inventory efficiently while tracking product expiry dates. It helps reduce food wastage by providing alerts for near-expiry items and maintaining accurate stock records.

## Features
Add, update, and delete grocery items
Track product quantity and expiry dates
Alerts for near-expiry products
Organized inventory management
User-friendly system

## Technologies Used
Python 
SQL
HTML
Microsoft Excel

## Use Case
This system can be used by small grocery stores or households to manage inventory and avoid losses due to expired products.
